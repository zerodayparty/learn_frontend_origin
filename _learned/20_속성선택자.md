# 🟩 CSS 속성 선택자 (Attribute Selector)  

<br>

## 🟢 1. 대괄호 [ ] 의 정체  
- **CSS에서 대괄호 `[ ]`는 "속성 선택자(Attribute Selector)"**  
- HTML 태그 안에 들어있는 **속성(Attribute)** 과 그 **값(Value)** 을 지정해서 원하는 요소를 찾아내는 방법이다.  

<br><br>

## 🟢 2. 사용 예시와 구조 비교  

### 🟡 HTML 코드  
```html
<html data-theme="dark"> <!-- html 태그 안에 data-theme 이라는 속성이 있고 값은 dark 이다 -->
```

### 🟡 CSS 코드 (속성 선택자 사용)  
```css
[data-theme="dark"] { /* data-theme 속성값이 dark 인 모든 요소를 선택한다 */  
    --color-bg: #111622; /* 배경색 변수를 어두운색으로 바꾼다 */  
    --color-text: #f2f5f3; /* 글자색 변수를 밝은색으로 바꾼다 */  
}  
```

<br><br>

## 🟢 3. 주요 CSS 선택자 종류 비교 표  

| 선택자 종류 | CSS 표기법 | 설명 | 예시 |  
| :--- | :--- | :--- | :--- |
| **태그 선택자** | `html` | 태그 이름 그대로 선택함 | `html { margin: 0; }` |  
| **클래스 선택자** | `.dark` | `class="dark"` 속성을 가진 요소 선택함 (점 `.` 사용) | `.dark { color: red; }` |  
| **아이디 선택자** | `#main` | `id="main"` 속성을 가진 단 하나의 요소 선택함 (샵 `#` 사용) | `#main { width: 100%; }` |  
| **속성 선택자** | `[data-theme="dark"]` | 특정 속성과 속성값을 정확히 가진 요소 선택함 (대괄호 `[]` 사용) | `[data-theme="dark"] { background: black; }` |
